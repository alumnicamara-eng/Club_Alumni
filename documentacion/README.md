# 🎓 Club Alumni

## 📌 Descripción
Club Alumni es una aplicación diseñada para conectar a los antiguos alumnos de Cámara FP con el centro educativo. 

El objetivo es crear una comunidad activa donde los exalumnos puedan mantenerse en contacto, participar en actividades y comunicarse entre ellos.

La aplicación incluirá:
- 📅 Calendario de actividades con inscripción
- 💬 Foro de comunicación entre alumnos
- 🗨️ Chats privados entre usuarios

## Diseño App y Funciones
- Pantalla de Inicio de Sesión con la opcíon de Que has olvidado la contraseña
- Pestaña Usuario que lleva a  administrar usuarios, donde se puede agregar usuarios, abajo existe una tabla con los usuarios creados actualmente donde se muestra el nombre, email, fecha de registro, rol (usuario o admin) y el estado si nunca ha entrado en la app pondra inactivo y si ya accedio y esta actualmente dentro de la app pondra activo.
- Pestaña Dashboard muestra todos los usuarios que estan en la app, los que estan actualmente conectados, los usuarios nuevos y los que todaia no han accedido. Además se ve los gráficos de los usuarios registrados en un determinado tiempo y un grafico que compara los usuarios que estan activos contra los que no han accedido nunca o actualmente no estan activos.
- Botones de importar y exportar csv para archivos excel
- Pestaña Reportes donde se muestra una tabla con las columnas Usuario, Descripción, Fecha de reporte, Estado, Admin, Id
  Pestaña Ajustes donde se muestra el correo electronico y el de incidencias.
    Notificacion (Opción para activar o desactivar las notificaciones por sms) además existe la posibilidad de tener un correo para recibir las notificaciones.
    Configuración de Seguridad (Autentificación en 2 pasos), solicitud cambiar contraseña con un select en este caso de 90 dias. Existe la opción de bloquear usuarios depues de varios intentos fallidos.
    Copia de seguridad: Tenemos la opción de activar o desactivar hacer copias de seguridad automática, seleccionamos la frecuencia de de las copías de seguridad. También se puede restaurar backup o copia de seguridad y limpiar datos antiguos ( estas dos ultimas son botones automáticos).
